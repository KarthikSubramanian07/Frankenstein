# Bench toolchain (Lane B real-compiler bench)

A small, real-compiler benchmark so Lane B can measure Digger byte-matches without waiting for Lane A's
GBADoom referee. Same contract (section 4), same `fn_` id scheme, but the targets are 20 original C
functions written today in a period GBA-game style. None of it is Doom, prBoom or GBADoom code.

## Compiler

| | |
|---|---|
| Compiler | `arm-none-eabi-gcc (GCC) 16.2.0` (Homebrew formula `arm-none-eabi-gcc`, `/opt/homebrew/bin`) |
| Binutils | `GNU objdump (GNU Binutils) 2.47` (Homebrew `arm-none-eabi-binutils`) |
| Flags | `-O2 -mthumb -mthumb-interwork -mcpu=arm7tdmi -ffreestanding -fno-builtin` (no `-flto`, no `-std`, so GCC 16's default `gnu23`) |
| Install | `brew install arm-none-eabi-gcc` (bottle, about 1 minute) |

Overrides: `BENCH_CC` and `BENCH_OBJDUMP` point at another compiler or objdump (for example devkitARM's).
Lane A uses devkitARM r68 (GCC 16.1.0) at `-O3`; the bench is GCC 16.2.0 at `-O2`. Codegen is close but not
identical, so the bench measures the Diggers' matching skill, not GBADoom results.

## Layout

```
crew/bench/
  answers/        answer key: one function per .c, data.c (globals), bench.h, names.json (id -> name)
                  blocked for the crew by crew/guard.py (FORBIDDEN includes crew/bench/answers)
  build.py        python3 crew/bench/build.py  -> regenerates out/ and answers/names.json
  core.py         stdlib ELF32 reader, extraction, relocation-aware compare, anonymized disassembly
  referee.py      python3 -m crew.bench.referee serve --port 7101   (contract section 4)
  out/            manifest.json, asm/<id>.s, ctx/<id>.h, targets.json, bench.bin (committed)
  test_bench.py   .venv/bin/python -m pytest crew/bench
```

## Use it from the crew

```
python3 -m crew.bench.referee serve --port 7101
REFEREE_URL=http://127.0.0.1:7101 FRANK_MANIFEST=crew/bench/out/manifest.json <crew command>
```

`crew/target.py` reads asm through the manifest's `asm_path`; ctx is not under `lab/out/ctx`, so it falls back
to `GET /context/{fn}`, which returns `{"fn": ..., "ctx": "..."}` (what `HttpReferee.context` expects).
Candidates must define exactly one function named exactly with its id, e.g. `s32 fn_08000250(s32 a, s32 b, s32 c)`.

## Decisions

- **One function per answer file.** The candidate is compiled alone with its ctx header, so the target is
  compiled under the same conditions: no same-file inlining or IPA, and calls are real `bl` relocations.
  Globals live in `data.c`, so no table is constant-folded into a target.
- **Ids.** Functions are ordered by a salted hash of their name (no alphabetical leak) and laid out from
  `0x08000200`, each aligned to 4 bytes. Globals become `data_<8 hex>` (salted SHA-1), struct types
  `struct_<6 hex>`, and struct fields `f_<offset>` (offsets proven at build time with `_Static_assert`).
  `build.py` fails if any original name shows up anywhere in `out/`.
- **ctx header.** Typedefs (`u8 … s32`, `fixed_t`), the anonymized structs the function touches, `extern`
  declarations for its globals, and prototypes of its callees (parameter names stripped). The target's own
  prototype is left out. The header is passed with `-include`, so compiler errors point at candidate lines.
- **Split.** 6 of 20 functions are heldout: sorted by size, 3 of every 10 sampled with `random.Random(7)`.
- **Difficulty** is `0.55*min(1, size/96) + 0.035*branches + 0.06*calls`, capped at 1.
- **rom_sha1** is the SHA-1 of `out/bench.bin`, which holds every function's bytes at its fake address.
  Relocations are left unresolved (addends only).
- **out/ is committed.** It is regenerated byte-for-byte by `build.py` and contains no answer text, and
  teammates without the toolchain can still read the manifest and asm. The referee itself needs the compiler.
- **rebuild** (`POST /rebuild {recovered_dir}`) re-checks every `fn_*.c` in the directory. `identical` is true
  only if all of them MATCH, and `rom_sha1` equals `original_sha1` only then. There is no real ROM link; it
  reports `method: "source-tree"` and `bench: true` to keep the contract shape. `/patch` returns 501.

## How faithful matching is

- Comparison is per instruction unit (instructions plus literal-pool words) over the function's ELF symbol
  range, and the size must match exactly. `match_pct` is matching units divided by target units, times 100.
- Relocations compare by type plus target identity rather than raw bytes: calls must hit the same `fn_` id or
  libgcc helper, and literal-pool words must name the same `data_` id with the same addend (so `&tbl[3]` is
  not `&tbl[4]`). Section-relative words (switch jump tables in `.rodata`) compare by a fingerprint of the
  referenced section's contents with its jump targets normalised to function offsets.
- Known gaps: a candidate that defines extra functions with their own `.rodata` changes the fingerprint and
  gets a false PARTIAL (tell Diggers to define exactly one function). Data contents of globals are not checked
  (only references), which is the same as linking against the original data. Lint is L001 to L004 (same rules
  as `crew/referee.py`) plus L008 (4 or more consecutive asm-looking lines anywhere in the source); Lane A's
  L005 to L007 and L009 are not implemented here.
- Lane A's referee is authoritative for GBADoom; bench numbers must be labelled "bench" in metrics.
