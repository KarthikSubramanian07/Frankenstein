# GPL notice for the committed GBADoom builds

`lab/out/*.gba` are builds of GBADoom (doomhack, https://github.com/doomhack/GBADoom, GPL v2 or later),
which is derived from PrBoom and the Doom source release by id Software. They are not our work. They contain
no game data (no WAD).

`target.gba` and the ROMs derived from it are built from GBADoom with 11 small source edits of ours (the
"variant", made so a model can't match a function by reciting GBADoom from memory). During the event the
edits are kept private so the agents can't see them. **Written offer:** we will publish the exact edits
(`variant.patch`) and the build script in this repository after judging on 2026-11-07, and anyone can
request them at any time by opening an issue here. The unmodified GBADoom source is at the link above.
