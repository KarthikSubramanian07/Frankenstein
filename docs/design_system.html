Frankenstein, the game

The demo is one retro video game played in scenes, with the live Play / Rebuild split at its heart, each in the genre that fits the moment. Same midnight sky, same pixel HUD, same narrator, same evidence rule throughout. Lane C builds these exactly; Lane D's OBS scenes use the same names.

Fonts load from Google Fonts. All numbers here are placeholders; on stage they come only from real run files.
