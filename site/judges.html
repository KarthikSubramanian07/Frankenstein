TL;DR for judges

What it is
AI agents rebuild a lost game's source code from the cartridge. It's for game preservation groups and rights holders, because 87% of classic US games are critically endangered and their code is gone.
What's proven
A piece only counts if it's byte-identical: the compiler turns the agents' C into the original's exact bytes. Put back into Doom, the rebuilt game has the same checksum.
The numbers
83 of Doom's 568 game functions are back. That's 2.34% of the code by size, because the crew starts with the small ones.
Try it
Press Enter at our table and watch two agents recover a function live. Then play Doom on the controller, or scan the QR code to play it on your phone.
Not done yet
Doomguy's face (1,164 bytes) isn't recovered, and the habit library hasn't beaten noise on unseen code. Both are said plainly below.

Trust but Verify

Agents lie. The referee doesn't.

judged on

Source: the event page, cerebralvalley.ai.

A claim is only a claim
Each agent stakes its claim before it sees the verdict, and the Checker re-runs the referee on every one. see a caught lie
Lies caught
In round two the Checker caught 5 real false claims, and the referee refused every one. DECISIONS 13:58
Fakes thrown out
A fake is C that matches by tricking the compiler, like a stray volatile; the easy held-out runs rejected 3 to 5 each, and none got through. crew/EXPERIMENTS.md

The System That Gets Better

Habits earn their place, or get retired.

judged on

  • systems that get measurably better with every run

Source: the event page, cerebralvalley.ai.

Habits, never answers
After each match the crew keeps a general lesson, never the code, and drops any habit that copies 3 lines of the answer. crew/README.md
Kept only on evidence
A habit is adopted after 3 good uses and retired after 4 bad ones; one training run adopted 3 and retired 4. see the habits
Tested on unseen code
170 of 568 game functions are held out (never trained on), and the library is frozen while they're tested. crew/EXPERIMENTS.md
Honest result
Held out, the library hasn't beaten noise: 29 vs 29 of 40 on easy code, 6 vs 6 of 20 on hard code, so we don't claim it helped. DECISIONS 14:06

Meta Model API

Best Use of Meta Model API

Muse is Frankenstein's hands.

judged on

  • the best use of the Meta Model API
  • Muse is load-bearing, not decoration

Source: the event page names the prize; the second line is our reading.

Every line of recovered C
Six Muse Spark agents write C in a loop with the referee as their tool: write, compile, read the diff, try again. crew/digger.py
Wonder for the stubborn ones
When Snap says escalate, Muse Wonder takes over; the first Doom run used 103 Spark calls and 11 Wonder calls for $0.73. doom_r01 metrics
It also teaches and names
Muse writes the habits and guesses the function names, which we show in violet. names.json
Without it
Nothing writes the C, and the referee has nothing to judge.
Honest limit
Wonder has no public price yet, so we count it at Spark rates and mark the cost as estimated.

Best Use of Subquadratic

SubQ Snap is its judgment.

judged on

  • Snap changes what the crew does, and it's measured

Source: our reading; no written criteria were published that we could find.

The whole game in one read
Snap reads every function's machine code in one 384K window and sets the work order; in the first run that was 1.39M tokens. doom_r01 metrics
Keep, escalate or abandon
After each miss, Snap decides where the next Muse dollar goes, in well under a second. see its calls
The fake gate
Every MATCH also needs low fake and recital odds from Snap before it's accepted. crew/checker.py
Eyes on the screen
Play the game, and Snap picks what's on screen to rebuild next, then checks a patch changed only what we said. DECISIONS 12:00
Without it
Muse digs blind, and nobody reads the whole game at once.
Honest limits
Plain-words routing is a hint, 5 to 7 times better than random. Snap on vs off was 6 vs 4 of 20 on hard code: a weak hint, not a result. DECISIONS 13:58

MongoDB

One collection per habit library

Google Gemini

Google Gemini

Gemini is the second opinion.

judged on

  • Gemini is used meaningfully

Source: our reading; no written criteria were published that we could find.

A different lab, on every match
When the bytes match, Gemini checks the C for fakes next to Snap, in parallel, so it adds no wait. crew/gemini.py
A vote that counts
A match is rejected if Gemini is near-certain it's a fake, or if both labs flag it. crew/README.md
It drew the lab
Every illustration on our home page was generated today with Gemini. generate_art.py
Without it
One lab's opinion on fakes, and a site with no pictures.
Honest limit
Gemini is advisory, and we haven't run Gemini on against off, so its effect isn't measured yet.
