Chapter I · The patient

Emulators keep games playable. Source code keeps them alive.

For most classic games, only the compiled cartridge survives. It still runs, but nobody can fix it, port it or change it.

First users: preservation groups and rights holders. Only games we're allowed to rebuild.

Byte-identical, or it's out.

Chapter II · You ask

Ask for a body part. Get proof back.

Open a chat in ASI:One and ask in plain words. SubQ Snap reads the whole game and points at the function behind it. The agent only says "done" when the referee says MATCH.

Chapter V · It changes again

Once the code is back, the game can be fixed.

Edit the recovered C, and the referee patches it in place and lists every function that moved. Change one constant, and exactly one byte changes. Then the room plays it on their phones.

The organs · Built with

Sponsors are the organs, not the logos.

Muse writes it. Snap judges it. The compiler proves it. MongoDB remembers it. ASI:One lets anyone ask for it.
