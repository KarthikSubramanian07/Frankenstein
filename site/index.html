  • Meta Model APITHE HANDS

    Writes every line of recovered C.

    • Every Digger is a Muse Spark loop with the referee as its tool.
    • Stubborn functions escalate to Muse Wonder when Snap says so.
    • Muse also writes the habits and the names.

    Without it: nothing writes the C. The referee has nothing to judge.

    103 + 11 Spark and Wonder calls in the first Doom run doom_r01

  • THE JUDGMENT

    Reads the whole game at once and decides where every attempt goes.

    • Triage: every game function's disassembly in one 384K window.
    • After each miss: keep going, escalate to Muse Wonder, or abandon.
    • Gates every match for fakes, and watches the live game to pick what to rebuild next.

    Without it: we pay Muse to dig dead ends, blind to the rest of the game.

    37 Snap decisions in doom_r01, 842 ms average; triage read 1.39M tokens

  • THE FRONT DOOR
    recover the faceMATCH, per the referee

    Ask for a recovery in a chat. Get proof back.

    • Ask in plain words in ASI:One.
    • The Excavator agent runs a crew job, then asks the Referee agent, agent to agent.
    • It answers only with the Referee's verdict.

    Without it: only our team can ask, and nobody can check our claims for themselves.

    2 agents live on Agentverse: Frankenstein Referee and Excavator

  • MongoDB AtlasTHE MEMORY

    Remembers every trick, so the next game is faster.

    • Each habit library is its own collection; held-out libraries stay frozen.
    • Every run event and every run's metrics are mirrored to Atlas.
    • Habits are adopted or retired on evidence.

    Without it: every run starts from zero, and nothing remembers why.

    38 habits learned in the first Doom run doom_r01

  • Google GeminiTHE SECOND OPINION

    A different lab double-checks every match.

    • Reviews every byte match alongside Snap, in parallel, so it adds no wait.
    • A match is rejected when Snap is sure, both labs flag it, or Gemini is near-certain.
    • It also drew every illustration on this page.

    Without it: one lab's opinion on fakes, and a page with no pictures.

THE REFEREE

Byte-identical, or it's out.

Every piece of C the agents write is compiled with the game's own toolchain and compared, instruction by instruction, against the original. The referee has never told a joke.

    1 The game is dead

    Emulators keep games playable. Source code keeps them alive.

    For most classic games, only the compiled cartridge survives. It still runs, but nobody can fix it, port it or change it.

    First users: preservation groups and rights holders. Only games we're allowed to rebuild.

    3 The crew digs

    with

    Muse writes it. The referee checks it.

    1. Dig. Agents read the compiled game and write C, one function at a time.
    2. Check. A compiler rebuilds every piece. Byte-identical or it's out.
    3. Decide. Snap picks what's next: keep going, escalate to Muse Wonder, or move on.

    3 The crew learns

    with

    Every game we bring back makes the next one faster.

    Each match teaches the crew a habit, never an answer, kept in MongoDB Atlas. Habits are adopted or retired on evidence, and we test them on functions they never saw.
