STAGE 1

How a piece gets in

The ROM is cut into anonymous functions named only by address, like fn_08xxxxxx. No names, no hints. Each function is one piece, and a piece only goes back into the game when three separate parties agree.

  1. 01 / WRITE

    DIGGER

    An agent on Muse Spark reads one function's assembly and writes C for it, then asks the referee. Many Diggers work in parallel.

    "I matched it." CLAIM

  2. 02 / DOUBT

    CHECKER

    Trusts no Digger. Re-runs every claim with a fresh referee call and screens every match for tricks, like raw addresses or volatile used to coax the compiler.

    "Prove it." LIES COUNTED

  3. 03 / PROVE

    REFEREE

    Compiles the C with the original toolchain (devkitARM GCC, GBADoom's own flags minus LTO) and compares every instruction.

    Byte-identical or nothing. MATCH

STAGE 2

The evidence rule

Agents are good at sounding sure. So every screen, every chat answer and this page keep two kinds of statement apart.

BRIGHT = PROVED

Checked by the compiler. Match percentages, checksums, the exact instruction that differs.

  • MATCH 100%
  • ROM CHECKSUM IDENTICAL
  • DIFFERS AT INSTRUCTION 4
  • 1 FUNCTION CHANGED

VIOLET ? = OUR GUESS

Inferred by a model. Names, descriptions, types. Useful, never presented as fact.

  • UPDATE FACE WIDGET?
  • WEAPON STATE TICK?
  • struct player?
  • "handles the pain face"?

? = OUR GUESS. EVERYTHING ELSE IS PROVED.

STAGE 4

Four lanes, one contract

The team splits into four lanes that share only file shapes, two HTTP APIs and one append-only event log, all defined in contracts/.

  • A

    THE LAB

    Builds GBADoom reproducibly without LTO, splits it into fn_ functions, and runs the referee and the fakematch linter. Home of the ASI:One agents.

  • B

    THE CREW

    The Diggers, the Checker, the idiom library and the held-out experiment. Writes every run to events.jsonl and metrics.json.

  • C

    THE STAGE

    Retro-game scenes driven only by the event stream: Title, Split, Hi-score, Versus for every rejected claim, and a Time trial for the results.

  • D

    THE CREATURE

    Doom running in an emulator, healing as its code comes back, the rebuilt ROM swapped in, and a phone page so the room can play.

STAGE 5

Built with

Each platform has one job in the loop. The referee, not any model, has the last word.

  • MUSE SPARK

    on the Meta Model API

    Powers every Digger. It reads assembly, writes C and calls the referee as a tool. Easy functions start at lower reasoning effort.

  • SUBQ SNAP

    by Subquadratic

    Reads the whole program's disassembly in one window to triage every function by difficulty, and takes a second look at each match for fakes.

  • ASI:ONE

    agents by Fetch.ai

    Agents on Agentverse let anyone ask, in a chat, whether a fix really compiles to the bytes it claims.

  • MONGODB ATLAS

    the idiom library

    Stores generic compiler habits learned from accepted matches. Never the answers: idioms that copy a solution are rejected.
