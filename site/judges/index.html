For judges for the people with the clipboards

Frankenstein in 30 seconds.

  • Who it's for

    Game preservation groups and rights holders. Games they're allowed to rebuild, never any game.

  • The problem

    87% of classic US games are critically endangered (VGHF and SPN, 2023). For most, only the compiled cartridge survives: it runs, but nobody can fix it, port it or change it.

  • What it does

    Coding agents read the compiled game and write its C again, one function at a time. A compiler accepts a piece only if it becomes the exact original bytes. Doom is our first patient.

  • Try it at our table

    1. Press Enter. You just hired two agents. Watch them dig, live, until the referee stamps MATCH.
    2. Pick up the controller. It's Doom, running.
    3. Scan the QR code. Now it's on your phone.
REAL
Every MATCH (the referee re-runs it in 0.1 to 0.2 s), the checksums, the costs, every Snap and Gemini call, and the live dig you start.
REPLAY
Any screen with the REPLAY badge is a recorded real run, played back faster. Nothing on it is staged.
DISPLAY RULE
Doomguy's static face means "code we haven't recovered yet". We chose that rule, and we say it out loud.
our guess?
Function names, what a function does and Snap's routing are inferred, always violet with a "?".

Muse writes it. Snap judges it. The compiler proves it. MongoDB remembers it. ASI:One lets anyone ask for it, and Gemini gets a second look. Not at our table? Walk the story in five chapters.

Problem statement 1 of 3

Software Archaeology

Only the cartridge survived. The C comes back.

JUDGED ON

  • reconstruct software from imperfect evidence

Source: the event page, cerebralvalley.ai.

↑ All tracks
Evidence, not memory
Agents see only anonymous fn_ ids, Thumb disassembly and a context header. The real source is locked away as the answer key, and crew/guard.py blocks every read of it.
A scrambled patient
Our private Doom build has 11 body-only edits, so recited source can't match it. From memory alone, Muse compiled 0 of 20 Doom functions; with the real headers and compiler feedback, 3 of 20, none of them ones we changed. DECISIONS 13:28
Proved instruction by instruction
Each candidate compiles in a pinned devkitARM container and is compared to the original, instruction by instruction. Calls and addresses must point at the same id. One check takes 0.1 to 0.2 s.
Same bytes, same checksum, same game
The referee splices the agents' compiled functions back into the ROM and hashes it. With the 28 recovered pieces in, the SHA-1 is identical: d936259b…
And it can change again
Change one constant in recovered C and exactly one byte of the ROM changes. That's what source code is for.
Honest limits
Today's wins are Doom's smallest functions (120 bytes or less). Doomguy's 1,164-byte face isn't recovered: 2 attempts, best 0.7%. The static face is a display rule, not a recovery. crew/STATUS.md

Problem statement 2 of 3

Trust but Verify

Agents lie. The referee doesn't.

JUDGED ON

  • verify what other agents ship before it merges

Source: the event page, cerebralvalley.ai.

↑ All tracks
A claim is only a claim
A Digger stakes its claim ("Matched it. Pretty sure.") before it sees the verdict. The Checker re-runs the referee fresh on every claim. No agent ever marks its own work done.
Matching bytes aren't enough
A MATCH coaxed with volatile, absolute-address casts, goto chains, padding or cast chains is thrown out. Every held-out run rejected 4 fakes, and let 0 through. doom_r02 to r04
Two labs screen what bytes can't
SubQ Snap and Gemini score every match for fakes and recited source, in parallel. Snap rejects at 0.85; Gemini alone at 0.95, or at 0.7 when Snap agrees.
Hard to talk into anything
Pasted C is linted before and after macro expansion, then compiled with no network and an empty .env. We found and fixed an include trick that could have leaked keys to a chat user. SECURITY.md
Honest limits
No false claim has been caught yet: until claim-first landed, a Digger could only claim after a MATCH. On the easy held-out set Snap's gate rejected nothing (highest score 0.68); the deterministic rules caught all 4 fakes per run.

Problem statement 3 of 3

The System That Gets Better

Habits earn their place. Or they're retired.

JUDGED ON

  • systems that get measurably better with every run

Source: the event page, cerebralvalley.ai.

↑ All tracks
Habits, never answers
After each match, the Distiller keeps a generic lesson, like 0x80000000 built with movs plus lsl, never the code. A habit that shares 3 lines with the answer is rejected.
Kept on evidence
A habit is adopted after 3 uses at or above the library's quick-match rate, and retired after 4 or more at 15 points below it. Retired habits are never offered again.
Tested on code it has never seen
170 of Doom's 568 game functions are held out. The library is frozen before a held-out run, and its SHA-1 is the same afterwards, so the test never teaches it.
The first run learned 38
doom_r01 learned 38 habits while matching 28 of 30. doom_r01/metrics.json
Honest result
On 40 held-out functions: library on 30, off 28, at the same 1.50 attempts per match. That's within noise, so we don't claim it helped. A harder round with repeats is running. crew/EXPERIMENTS.md

Meta Model API

Best Use of Meta Model API

Muse is Frankenstein's hands.

JUDGED ON

  • the best use of the Meta Model API
  • Muse is load-bearing, not decoration

Source: the event page names the prize; no written criteria were published, so the second line is our reading (docs/MESSAGING.md).

↑ All tracks
Every line of recovered C
Each Digger is a Muse Spark 1.3 tool-calling loop with the referee as its tool: write, compile, read the diff, try again. Six run in parallel.
Wonder for the stubborn ones
When Snap says escalate, the function moves to Muse Wonder 1.0. In doom_r01: 103 Spark calls and 11 Wonder calls, $0.73 together. muse.by_model
It also teaches and names
The Distiller that writes the habits is Muse, and so are the function names, shown violet with a "?".
An effort ladder
Easy functions start at medium reasoning effort and climb back to high after 3 misses. Prompts are byte-stable, so the cache hits.
Without it
Nothing writes the C. The referee has nothing to judge.
Honest limits
Wonder has no published price yet, so Doom costs count it at Spark rates and are marked estimated.

Best Use of Subquadratic

SubQ Snap is its judgment.

JUDGED ON

  • SubQ is load-bearing: it changes what the crew does, and it's measured

Source: our reading (docs/MESSAGING.md). No written criteria were published that we could find.

↑ All tracks
The whole game in one read
Triage puts every function's disassembly in one 384K window and sets the work order and each function's budget. In doom_r01 it read 1.39M input tokens.
Keep, escalate or abandon
After every miss from the second attempt on, Snap decides where the next Muse dollar goes. 37 Snap calls in doom_r01, 842 ms on average. snap.by_op
The fake gate
Every MATCH also needs low fakematch and recital odds from Snap before the Checker accepts it. It rejects at 0.85.
Eyes on the screen
Play it, and we rebuild it: the director watches live frames and picks what to rebuild next, in 2.4 s. Eyes compares two frames and confirms a patch changed what we said, and nothing else (0.68 s, p 0.999).
Without it
Muse digs blind, and nobody reads the whole game at once.
Honest limits
The router is a hint, 5 to 7x better than random, not precise: it ranked the face #1 at 12:20 and missed the top three at 12:56. Held out, Snap on vs off was 30 vs 29 of 40, within noise, with a since-fixed bug skewing it against Snap.

MongoDB Atlas

MongoDB

MongoDB is the memory.

JUDGED ON

  • Atlas is a real component, not a logo

Source: our reading (docs/MESSAGING.md). No written criteria were published that we could find.

↑ All tracks
One collection per habit library
Each library is its own Atlas collection, like idioms__doom_lib, seeded from its file on first use. A frozen held-out library stays frozen.
The run record
Every run event is mirrored to events and every run's metrics to runs, so runs can be compared with a query.
Verdicts travel with the habit
Adopted or retired, a habit's status lives with it, so the next run inherits the evidence, not just the text.
Honest about the backend
Every metrics.json names its library_backend, and the Stage only says MONGODB when the run really used Atlas.
Without it
Every run starts from zero, and nothing remembers why.
Honest limits
Atlas went live at 13:05, after the morning runs: doom_r01 learned its 38 habits into a local JSON file, which stays on as the offline mirror. DECISIONS 13:05

Google Gemini

Google Gemini

Gemini is the second opinion.

JUDGED ON

  • Gemini is used meaningfully

Source: our reading (docs/MESSAGING.md). No written criteria were published that we could find.

↑ All tracks
A different lab, on every match
When the bytes match, Gemini reviews the C for fakes and recited source alongside Snap, in parallel, so it adds no wait.
A vote that counts
A match is rejected when Snap is sure, when Gemini is near-certain (0.95), or when both flag it (0.7 with Snap agreeing).
In the live dig
In our live rehearsal run, both matches got a Gemini review next to Snap's. runs/r01, second_opinion_reviews
It drew the lab
Every illustration on our site was generated today with Gemini, from site/tools/generate_art.py.
Without it
One lab's opinion on fakes, and a site with no pictures.
Honest limits
Gemini is advisory and off the critical path. It joined the Checker at 12:11, after the held-out runs began, so we have no measured effect yet.
