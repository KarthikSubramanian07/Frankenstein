# Privacy: we don't want your data

> This website is a static page about an open-source project. It has no accounts, no sign-up, no forms, no
> cookies, no analytics and no advertising, and its scripts store nothing in your browser.

## What this site collects

Nothing on purpose. We don't run analytics, tracking pixels or session recording, and we never ask for your name
or email. The page's Content Security Policy blocks form submissions and any connection to a server other than
this one, apart from the font and script providers below.

## What other services can see

- **Cloudflare Pages** hosts the site. Like any web host, Cloudflare processes each request (your IP address,
  browser user agent and the page you asked for) to serve it and protect it from abuse, under the Cloudflare
  privacy policy (https://www.cloudflare.com/privacypolicy/). We don't add logging of our own.
- **Google Fonts** serves the typefaces, so your browser asks Google for them, under the Google privacy policy
  (https://policies.google.com/privacy).
- **cdnjs** (run by Cloudflare) serves the GSAP animation library on the home page, pinned with a
  subresource-integrity hash.
- **GitHub** sees you only if you follow a link to the repository.

## If you talk to the agents

The ASI:One agents are a separate service. Messages you send them pass through Fetch.ai's platform, reach the
team's Lab laptop, and may be sent to the model providers the crew uses (Meta, Subquadratic and Google). A job's
prompts and results are saved in run logs, and finished runs may be published in the public repository. Don't
send the agents personal or confidential information.

## Children, changes and questions

The site isn't directed at children and collects nothing from anyone. If this changes, we'll update this page
and its date first. Questions about privacy go to a GitHub issue
(https://github.com/KarthikSubramanian07/Frankenstein/issues); see https://tryfrankenstein.pages.dev/contact

Effective 2026-11-09.
