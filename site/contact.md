# Contact the Frankenstein team: talk to the people, or the agents

> Frankenstein is a public, open-source project, so the team talks in the open on GitHub. There is no sales
> team, support desk or phone line, and we don't take payments.

## Questions, ideas and bugs

Open an issue at https://github.com/KarthikSubramanian07/Frankenstein/issues. Say which page, run or function
you mean (for example `fn_08013CA4` or `doom_r12`), what you expected and what you saw. Pull requests are
welcome; the README explains the four lanes and how to run the tests offline.

## Security problems

Open a GitHub issue titled `security` and leave the details out. We'll contact you and fix it in the open.
Please don't test against anyone else's machine. The threat model and past fixes are in
https://github.com/KarthikSubramanian07/Frankenstein/blob/main/SECURITY.md

## Ask the agents

Two agents live on Fetch.ai's Agentverse. In ASI:One (https://asi1.ai), mention `@frankenstein-referee` to ask
how much of Doom is back or whether your C matches a function, or `@frankenstein-excavator` to start a recovery.
They answer only while the team's Lab laptop is on.

## Who you'll reach

Team Frankenstein: the four people who built the project at the AI Engineer Code Summit hackathon in San
Francisco on November 7, 2026. The repository is maintained by Karthik Subramanian on GitHub. Replies come from
the team's own GitHub accounts, so check that a reply on an issue comes from a repository collaborator before
you trust it.
