- **WASM/JavaScript package:** Nicholas VanCise, `@thenick775/mgba-wasm@2.6.0-beta.5`, MPL-2.0 according to its npm metadata. [Source at the npm release gitHead](https://github.com/thenick775/mgba/tree/10e81ce75384521f74ad3fff643236c26c925918), including [WASM bindings/build instructions](https://github.com/thenick775/mgba/tree/10e81ce75384521f74ad3fff643236c26c925918/src/platform/wasm). [Source at the npm release gitHead](https://github.com/kazuhikoarase/qrcode-generator/tree/83b7e8fe3fddd3b0368dbafd6ce56995bd25e3c8). The original copyright header remains in `core/qrcode.mjs`. The word QR Code is a registered trademark of DENSO WAVE INCORPORATED.
- **App icons:** drawn today for this page (Built today).
- **Game:** Doom by id Software, prBoom by its authors, GBADoom by doomhack. The game and shareware IWAD are separate from the emulator and this shell; see [DISTRIBUTION.md](DISTRIBUTION.md) and the team's judging-window decision. The static bundle copies only the explicitly supplied packaged game.

Dependencies are pinned in `package-lock.json`; `prepare.mjs` copies their runtime assets into ignored `core/`. The static bundle includes this attribution file and the three license files above. License texts were copied unchanged from the pinned upstream source commits. No emulator binary, game binary or IWAD is committed here.
