How to play

D-pad
Move and turn. Slide your thumb for diagonals.
FIRE · B
Shoot. Hold it while you move.
USE · A
Open doors, flip switches. Hold to run.
STRAFE · L R
Sidestep.
USE + STRAFE
Change weapon.
MAP · SELECT
Automap.
MENU · START
Doom's own menu.
Keyboard
Arrows move. Z fires (B), X uses (A), A / S strafe (L / R), Enter is Start, Backspace is Select.
